# Gemini Dictation

一個以 Google Gemini 為核心的語音轉文字工具，支援逐字稿、對話分行，以及影視字幕 SRT 製作。

## 主要功能

### 🎙️ 逐字稿
- 將音訊／影片轉成文字。
- 適合一般逐字稿、文章整理與內容校稿。
- 可使用自訂規則與詞彙表，協助處理人名、地名、專有名詞及特定用語。

### 💬 對話分行
- 依語意與說話內容整理成較自然的對話段落。
- 可搭配自訂規則與詞彙表使用。

### 🎬 影視字幕
針對需要時間軸的字幕製作，使用獨立的處理流程。

- 產生可直接下載的 `.srt` 字幕檔。
- 使用逐字時間資訊建立精準時間軸。
- 中文支援自然斷句，不再單純依固定字數硬切。
- 可自訂每行字幕的字數上限。
- 支援中文、英文、日文、韓文，以及自動判斷。
- 不同主要語言會套用相對應的字幕斷句、空格與標點處理方式。
- 可在輸出結果中直接修改文字、斷句、新增或合併字幕行。
- 修改後可按「確認修改」重新校正時間。
- 下載 SRT 前會防止尚未確認的修改直接被當成最新版下載。
- 提供尋找與取代功能。
- 提供編輯模式，方便處理較長的字幕內容。

> 影視字幕的自訂規則建議僅用於人名、地名、專有名詞或用語替換。大幅改寫文字可能影響時間校正。

## V5 → V9 主要優化

### V5
- 建立影視字幕模式的精準時間軸。
- 改善字幕自然斷句。
- 支援繁體中文輸出。
- 建立基本 SRT 產生與下載流程。

### V6～V7
- 強化字幕斷句與時間重新校正。
- 支援使用者修改字幕文字、斷句、新增及合併字幕行後重新計算時間。
- 加入較完整的字幕編輯流程與防呆。
- 改善長字幕與部分無法對應時間資料的處理。

### V8
- 開始處理多語言字幕需求。
- 增加主要影片語言概念，讓中文、英文、日文、韓文使用不同的字幕規則。
- 經過多輪測試後，保留穩定的單語言處理方式，避免為特殊混語情況改壞中文核心。

### V9 Final
- 加入「影片主要語言」選項：中文、英文、日文、韓文、自動判斷。
- 中文與日文字幕進一步整理標點與斷句規則。
- 日文保留適合字幕使用的 `？`、`！`、`…`、`〜` 等語氣符號。
- 加入「確認修改」流程，避免下載到尚未重新校正時間的舊版本。
- 修改字幕後重新校正時間，再下載最新 SRT。
- 加入影視字幕自訂規則提醒。
- 改善 Streamlit 編輯區的狀態保存，降低修改後因介面重新整理而遺失內容的情況。
- 新增較適合長字幕的編輯模式。
- 尋找與取代功能同步配合字幕編輯。
- 音檔重新辨識時清除上一份字幕的編輯與提示狀態。
- 長音檔分段調整為約 25 分鐘，以降低 API 請求次數。

## 建議使用流程

一般文字處理：

**上傳檔案 → 選擇處理模式 → 處理 → 校稿 → 下載**

影視字幕：

**上傳檔案 → 選擇主要影片語言 → 產生字幕 → 修改文字／斷句 → 按「確認修改」→ 下載 SRT**

如果修改了字幕內容或斷行，請再次按「確認修改」後再下載。

## 已知限制

- 影視字幕的主要目標是中文影片；英文、日文、韓文單一語言影片也可處理。
- 混合多種語言的音檔，實際辨識結果可能不如單一語言穩定。
- 方言或辨識資料不足的片段可能需要人工修正時間軸。
- 自動斷句屬於 AI 判斷，不可能完全符合所有人工字幕製作習慣。
- 影視字幕輸出後仍建議進行一次人工校稿。

## 安全性

本工具的公開版本由使用者自行輸入 Gemini API Key。

API Key 不應寫入 GitHub 原始碼，也不應直接放在公開的 `app.py` 中。

使用者輸入的 API Key 僅供該次服務使用，請勿將自己的 API Key 分享給其他人。

## 技術

本專案主要使用：

- Python
- Streamlit
- Google Gemini API
- Gemini Transcribe
- FFmpeg

本專案以實用與穩定為優先，影視字幕模式與一般文字處理模式採不同的處理流程，以維持字幕時間軸與一般逐字稿的使用體驗。
